# Terms of Use (Demo Project)

**Last updated:** 2026-08-18

CinReco Web is a personal portfolio project: a Flutter Web client for a
movie-recommendation API, built to demonstrate application and
infrastructure engineering. It is provided "as is," with no uptime,
support, or data-retention guarantees, and may be taken offline or
reset at any time.

## Use of the demo

- You're welcome to register your own account or use the shared demo
  account shown on the login screen to explore the app.
- Don't submit real personal data you wouldn't want stored in an
  unmaintained demo database — see the [Privacy Notice](privacy_policy.md).
- Movie metadata (titles, posters, descriptions, cast) is sourced via
  the backend API from [The Movie Database (TMDb)](https://www.themoviedb.org/)
  and belongs to its respective rights holders. This project is not
  endorsed or certified by TMDb.
- The recommendation logic itself runs entirely in a private backend
  service and is not part of this repository — this client only calls
  the public API surface.
