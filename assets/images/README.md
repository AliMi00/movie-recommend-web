# App Images

This folder contains general app images like placeholders and icons.

## Required Images:
- movie_poster_placeholder.png - Default image when poster is not available
- movie_backdrop_placeholder.png - Default image when backdrop is not available  
- user_avatar_placeholder.png - Default user profile image
- app_logo.png - Main app logo
- app_icon.png - App icon for various platforms

## Image Specifications:
- All images should be in PNG format for transparency support
- Use appropriate resolutions for different use cases
- Maintain consistent visual style with the app theme
